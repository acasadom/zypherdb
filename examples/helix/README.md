# helix

The access-control system of Helix Biolabs, a biomedical research lab, and a simulated day of it:
door controllers in one process and a monitor in another, on one database.

    python -m examples.helix.simulate [--database DIR] [--every MINUTES] [--verbose]

Walkthrough: [docs/examples/helix.md](../../docs/examples/helix.md).
